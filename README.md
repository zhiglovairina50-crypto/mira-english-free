# MIRA English — бесплатная версия

Продолжение Starlight Pink v08/v0.9: сохранены исходный дизайн, портрет, 10 разделов, 38 уроков, 108 вопросов, чтение, основы и тематический поиск страниц.

Бюджет приложения: 0 ₽. Нет платного сервера, вызовов Yandex API, ИИ, облачного распознавания фотографий и серверной синхронизации. Свободного ИИ-чата нет: поиск показывает готовые объяснения курса.

## Прогресс

Результаты хранятся в localStorage этого браузера. В разделе «Для родителей» скачай JSON-копию, передай её на другое устройство и выбери в Мире. Перед импортом доступны описание, объединение или явная замена результатов. Неподдерживаемые и повреждённые файлы отклоняются. Очистка браузера или удаление PWA могут удалить местные результаты. Предыдущее локальное сохранение не заменяет скачанную резервную копию.

## Голос

Озвучка использует SpeechSynthesis. Русский и английский голоса выбираются отдельно. Наличие и качество голосов зависят от устройства; часть голосов может требовать интернет. Анимация рта базовая, приблизительная.

Диктовка использует SpeechRecognition / webkitSpeechRecognition, если API доступен и пользователь разрешил микрофон. Браузер может передавать речь своему провайдеру. Платные голосовые API MIRA не подключены, аудиозаписи не сохраняются. «Только на устройстве» отказывает при отсутствии локальной поддержки; незаметного переключения на облако нет. Распознанный текст проверяется пользователем до поиска. Запасной способ — текст или системная диктовка клавиатуры телефона.

## PWA

Рабочие исходники: web/. Публичная сборка: dist/. Все пути относительные, включая service worker и manifest. После первой успешной загрузки service worker сохраняет учебную оболочку и изображения для офлайн-работы. Диктовка и сетевые голоса могут не работать офлайн. iPhone: Safari → «Поделиться» → «На экран Домой». Windows/Android: установка через меню поддерживаемого браузера.

## Размещение

Текущая публикация использует GitHub Pages Free из публичного репозитория, без функций, платных дополнений и покупки домена. Действуют бесплатные лимиты сервиса. Платные подключения и автоматический переход на платный тариф не настроены. При изменении условий допустимы бесплатный перенос или остановка; расходы требуют отдельного решения владельца.

## Проверка

`node test_free.cjs` — проверки прогресса, импорта, голосовых отказов и отсутствия платных сетевых клиентов. Исторические backup, сервер, env и приватные отчёты исключены через .gitignore. Прогресс посетителей и их JSON-копии не загружаются на сервер. Фактический статус испытаний: FREE_EDITION_REPORT_2026-10-22.md.
